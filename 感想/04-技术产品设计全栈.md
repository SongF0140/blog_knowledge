> 2024 年前后入学的那批人，大多沿着同一条通道往后端游。这条通道现在正在消失。这篇聊两件事：全栈的地基怎么变了，产品与设计又该怎么想——以及为什么门槛变高反而是好事。

## 一、技术与全栈：地基变了

### 鲑鱼

和大多数人一样，作为 2024 年前后入学的学生，我跟着网络平台的流量推送走。我们就像繁殖期北海道的鲑鱼，一股脑钻进后端的学习历程：看几十小时的网课「打基础」，每天刷 LeetCode 保持代码手感，用磨时间的方式换 API 调用技术上的提升。

这套叙事在18-22年是有验证的。学长这么走过，岗位表上也是这么写的，你照着游，就能游到一张还不错的offer 面前。

然后 2025 年，基模爆发，这套叙事失效了。

失效的方式不是「变难」，是「变快」。说得清的业务代码，模型直接写，产出速度和质量越过初级工程师的平均线。以前抄一个产品要一个团队几个月，现在一个 agent 一晚上。我在《如何高效的学习》里写过一件事：评价体系本身没有出口时，往里面投入越努力，越是在替它免费运转。这条赛道的问题和那个排名一模一样——**不是你游得不够快，是河的方向变了。**

算法竞赛也没撑住，而且我已经不打了。一方面是 Codeforces 这类平台被一群虚荣的「嘉豪/嘉欣」们拿 GPT 搅成了筛子—— rating 还在涨，人早就换了；另一方面是我自己想明白了一件事：**算法竞赛的本质还是做题。** 它能证明选手解决某类思维难题的个人能力很强，但这种能力没法平移到工程上——工程里大多数时候直接调用库就完了，C++ 手写造轮子优化的那点性能，在整体成本里只占很小的一块。除了量化交易这种把极端性能直接换成钱的场景，我不认为古典算法还有什么真正的可用之处。

所以对我来说，算竞落幕不是被迫退场，是看清了它和工程的关系之后主动离场。**而剩下的回归热爱——对还留在赛场上的参赛者而言，比赛不再通向任何 offer 和筹码，它第一次变回了纯粹的样子：因为享受思考，所以持续思考。**

### 前后端不再泾渭分明

API 调用时代把软件职责切成前后端，切的逻辑是「人的学习速度太慢，分工能让每个人只精通一段」。这个分工本来就不科学——它是人类协作低效的产物。现在联调跑通比各自精通更关键，因为让 LLM 结合知识库搞定某一层的实现，比让一个人精通某一层快得多。

所以在应用层，我们不再需要那么深刻的底层实现细节——前人沉淀完善的文档摆在那里，模型背得比你熟。

**但这不意味着不需要计算机素养。恰恰相反，职责变了之后，素养变成了刚需。**

现在的职责是审查每一次提交的 diff。要审得动，你得懂编程思想，懂操作系统概念——这是现代软件设计和应用的源头基础。举个例子：agent loop 里的 hooks 权限拦截——每次工具调用前先过一遍策略检查，deny 优先，模型绕不过去——这套设计在 Linux 里长了几十年：内核把 syscall 拦在用户态和内核态的边界上验证，特权操作一个都漏不掉；LSM 在内核的安全决策点挂了一组钩子，SELinux、AppArmor 都插在这里；Linux-PAM 把认证做成可插拔的模块链，required 模块一票否决。hooks 是同一个设计问题在 AI 时代的最新解法。你没读过内核的这套机制，看到的 hooks 就是一堆神秘的配置项；读过，你看的是五十年来没变过的那个原则：**关键操作必须经过一个绕不过去的检查点。**

**AI 把「填分支」的活全接走了。人剩下的，恰好是「主干」。**

这个结论不是我新举出的，它就是我《如何高效的学习》那套方法的推论：查 Qt API 那种纯操作性任务，AI 现在连查带写全包了；408 计算机网络那种主干结构，AI 替你记住位置、但替你判断不了这个位置对不对；至于具身智能那种业界还在吵的领域，方向判断彻底没有模型可以代劳。

学习法没过时。它从「高效技巧」升级成了「分工边界」。

### 生产变便宜，验证变贵

顺着这条线往下走，会碰到一个反直觉的事实：**AI 时代最贵的不是写代码的人，是能判断这份代码对不对的人。**

我的日常已经变成这样：模型产出一大段实现，我逐块审 diff——它有没有引入幻觉出来的 API，边界条件漏没漏，权限处理对不对。写的过程只需要几分钟，审的过程比写慢得多。

这就是门槛变高的形式。以前门槛在「能不能写出来」，现在门槛在「能不能看得出它写得不对」。前者可以靠磨时间堆，后者只能靠主干——那些你在「打基础」阶段真正学进去的编程思想和系统概念，而不是抄在本子上的八股。

一个真实的例子：收口懒删除功能时，Agent 交来的代码看着完全正确——功能演示通过，页面上被删的内容确实消失了。但我往下翻 diff，发现它执行的是一条真删除的 SQL：把记录从表里物理删掉了，而不是打上隐藏标记。区别在哪？懒删除的定义是「记录留在库里、只是不展示」——因为内容治理要留快照、用户要能申诉，物理删除等于把审计能力一起删了。AI 对「删除」的理解停在字面：页面上看不见，它就认为删完了。这一层语义，代码和测试都验不出来，只有懂「删除有两种」的人才拦得住。

### OA 和数学圈的事，我想修正一个常见误读

最近 OA 爆破数学圈的事，很多人拿来说「AI 已经能做开创性研究了」或者反过来「它只配做低垂果实」。我觉得两种读法都没到点上。

它解决的是可形式化、有验证器的题——答案对不对，机器自己能判。漫长时间里数学家没有完整解出它们，说明的不是「这不算开创性难题」，而是**这类题的求解过程本身就是工程问题：在巨大的搜索空间里系统地推进，而不是需要发明新的范式**。费马大定理搁了 358 年，没人说它不开创——区别在于它需要的是人类还没发明的数学语言，而 OA 啃下的是人类已经铺好路、只是没人走得完的那段。

这个区分对开发者很重要。**遇到一个AI暂时干不了的任务，先分清它卡在哪：是需要新范式（真开创），还是搜索空间太大（工程问题）。** 前者别指望模型，后者别急着上人力——等一等工具，或者在验证器上下功夫，把问题改造成模型能自己判对错的形式。

排斥 AI 没有意义，因为它是更高生产力的工具。排斥的方式不是喊口号，是搞清楚你的任务落在搜索空间的哪一侧。

**以上是地基。地基变了，在上面盖什么、怎么盖，是另一件事。**

## 二、产品与设计：地基上面盖什么

### 产品

产品这一篇，得从《如何高效的学习》里那次拷问说起。Joye 问我「为什么用户不用 Codex 而用你的系统」，又问我「为什么还围绕 Codex 生态做插件」。那次对话之后，我把正在做的 CampusOverflow 推倒重做了一版：[CampusOverflow AI](https://github.com/SongF0140/CampusOverflow_HWA)，一个面向高校课程场景的问答平台。

改进版里我着重做了两件事，都是那次拷问换来的。

第一件，**agent 友好接入层**。平台带一个受控的 Agent Runtime：它能做站内检索、智能标签、相似问题推荐、辅助回答，但它不直连数据库——所有数据读写只能经过一层白名单业务接口，持服务间 token 才能进。也就是说，Agent 是这个平台的「持证访客」，不是「拿到钥匙的住户」。

第二件，**权限与安全机制**。高风险操作——删帖、封号、内容隐藏——Agent 连碰都不能碰，它只能创建一条待确认工单，进双环状态机，真实处置必须管理员本人确认后才执行。Agent 的每一次运行、每一次工具调用都有 trace id 和日志，可追踪、可回放、可审计。

做完这两件事，我意识到一个产品分野：**这个东西其实是 toB 的。** 学校和机构买它，要的不是聪明，是稳定和可审计——所以 Agent 必须关进笼子，所以集成必然是重型的。这不是缺点，是 toB 客户的出价方式：他们用「确定性」换钱。

但我想做的下一代不是这个。

是一个多解耦层：把「agent 友好接入」这一层抽出来做成独立产品，用户可以直接通过 Codex 这些通用巨头操作自己的内容——管理博文、理解对话，不再需要一个个单独的应用。它更偏 C 端：实现简单一些，巨头自带分发，容易传播，适合打响名气。

这两件事的顺序要分清楚：**恰恰因为是 toB，才不需要围绕生态做。** 重型集成、独立部署，客户买的就是确定性，生态位反而排在稳定和审计后面。围绕生态做，是 toC 的事，也是我的下一步：把 agent 接入层抽成多解耦层，让用户直接通过 Codex 这些通用巨头操作自己的内容——管理博文、理解对话，不再需要在一个个独立应用之间倒手。它实现更简单，巨头自带分发，容易传播。而对一个还没出名的开发者，它还有一层更实际的价值：**求职信号**。面试官打开链接就能看到你的东西被真实的人用着——这比简历上任何一行技术栈都难造假。

### 设计

技术和设计之间隔着一个根本的不对称：代码是有测试的。写完跑一遍，对就是对，错就是错，验证成本几乎为零。所以 AI coding 这条赛道跑得最快——反馈信号清晰，模型可以自己刷自己，反重力这类工具的每一次迭代都被测试接住了。但反过来看，这也意味着「写代码」这个动作是被替代得最干净的：一个可以被自动验证的生产环节，人没有理由继续占着。

文生图和视频是另一个世界。「这张图好不好看」没有编译器能判，本质上是抽卡：抽一百张，凭感觉留一张。想缩小奖池范围，只能靠 harness 工程——风格约束、参考图、一层层调 prompt——投入的成本和产出完全不成正比。

但抽卡的原因不是「设计没有对错」。设计有验证，只是又慢又噪：可用性测试要找人，A/B 实验要流量，转化率要等数据。验证环路太长，进不了模型那种一秒一次的训练闭环。**这才是抽卡的本质：对错的反馈回来得太慢。**

这个区别决定了两边的职业命运。

在代码这边，验证便宜，所以生产被机器接走，人退到验证端——审 diff、写测试、设计验证器，这是技术篇的结论。

在设计这边，验证又慢又贵，机器卡在生产端反复抽卡，而「判断哪张是对的」这件事，暂时只有人做得了。这就是 taste 的位置：它不在生成里，在筛选里。

但别急下定论「taste 不会被替代，所以设计产业会繁荣」。taste 的**执行**正在被压缩——reward model 天天在拿人类的选图行为当训练数据，可自动化的那部分审美判断，正在被缓慢吃掉。真正吃不掉的，是绑在具体人群和具体语境上的判断：你知道你的用户卡在哪，你知道这个方案为什么适合这群人而不是那张排行榜。

所以设计不会被替代的是「定义什么是好」的权利。而定义权不悬空存在，它由两样东西撑着：**一群信你判断的受众，和一份持续可查的判断记录。** 前者让你知道什么是对，后者让别人相信你知道。

**生产的抽卡化会淘汰只会执行的人，把「定义什么是好」推给少数有验证权的人。你想站在哪一边，取决于你手里攒下了什么：是能被模型复制的产出，还是复制不走的判断记录。**

### 页面设计：第一抓手

落到最具体的页面上，这套逻辑是这样工作的：前端不是被替代，而是「机械性地改页面」被替代了。因为前端反馈最快——改一行样式，刷新就看见结果。按技术篇的框架，反馈越快的环节，机器接管得越干净。

但要把「反馈快」说精确：前端是**快反馈**，不是**自动验证**。刷新看见的是结果，「这个结果好不好」仍然是人在判。所以机器接管的是「从意图到实现」的执行，接管不了意图本身——这正是 taste 的位置。

但页面因此更重要了，不是更不重要。功能可以被一夜复刻，页面是用户接触你产品的第一眼，它代表你传递给用户的一整套理念、情绪和感觉——这是面对客户的第一抓手。当实现不再稀缺，「页面传达了什么」就从加分项变成了主战场。

以往前端实现者和设计者之间隔着一道信息代沟：设计者不懂实现的边界，实现者不懂设计的意图，两边受各自知识面的限制，来回传话、相互折损。现在这道沟没有了——设计者可以直接协同 AI，完成从设计到落地的高效闭环。被替代的是传话的中间层，被放大的是「页面应该传达什么」的判断。

但代沟不是消失了，是换了个位置。设计者协同 AI 产出的大多是理想路径的页面：数据齐全、网络正常、屏幕刚刚好。真实的页面里还有一大半不长脸的部分——空状态、加载态、错误态、权限不足、极端小屏。这些没有设计稿可抄，AI 也很难主动想到，补齐它们依然需要工程素养。**旧代沟死于 AI，新代沟长在边界状态上。**

### 系统设计：编排

同一个逻辑在后端换了个形式出现。AI 调用的 SDK 和框架，受厂商限制——限流、计费、接口变更、区域可用性——会变慢、变贵、变得不可预测。写一个调用是机械的，让十个调用在这些限制下跑得又快又稳，靠的是编排：缓存、队列、降级、多供应商路由。

往深看一层，编排不是新东西，是分布式系统老问题的新皮肤：负载均衡、熔断、降级、fallback，微服务时代全都讨论过一遍。变的只是对象——上次均衡的是自家的服务节点，这次均衡的是脾气各异的模型厂商。又是那个熟悉的模式：**旧主干，新应用。**

但编排工具本身正在被产品化，路由、缓存、降级这些通用能力，很快就有人做成开箱即用的网关。值钱的不是编排动作本身，是**带业务语义的编排**：知道哪类请求的结果可以缓存多久，哪些任务能降级到便宜模型，哪些用户路径一个字都不能省。判断力又一次出现在链条的终点——和页面设计一样，这一节的两个题目，最后落到的是同一个地方。

成本也值得单独立一节：token 是新的电费。以前优化的是 CPU 周期和内存，现在要优化的是每一次调用的 token 账单和延迟预算。这块先记下方向，值得单独展开。

## 收束：门槛变高，需要的是「专家」

把两部分收拢起来，我对「学什么」的答案变成了一句话：**生产交给 AI，人守主干、验证和方向。**

- **主干**：编程思想、操作系统、系统设计——那些 AI 能引用但替你判断不了的东西。学法还是《如何高效的学习》那套：先搭结构，不碰细节，位置本身就是记忆。
- **验证**：审 diff 的能力、设计验证器的意识。这个只能靠真做过项目来堆——看一百篇教程不如审一次真实产出的错。
- **方向**：知道做什么、不做什么。 Joye 在[AI 之后的技术护城河 • Joye Blog](https://www.joyehuang.me/notes/1026-moats-after-ai)里把这件事收成了一个环：品味定方向，反馈改判断，信任靠记录攒下来。AI 把执行变成大路货之后，剩下能复利的就这个环。

门槛变高不是坏事。**它筛掉的恰好是鲑鱼式的努力**——那种不需要判断力、只需要服从性和时间的投入。工具越强，靠磨时间能换到的东西越少，靠判断力能换到的东西越多。

说到这里，得点名一个还在收割新生的生意：贩卖焦虑的培训班。招牌话术是「照着这条路径走，就能拿到高薪 offer」。但请想一件事：一门网课从录完那一刻就开始过时。它能帮你打基础，这有价值；但基础不等于方向——产业的方向每天都在变，它不在任何一条卖给你的路径里，它散落在博客、开源社区的讨论、和一线的人正在踩的坑里。AI 时代知识本身已经廉价，模型什么都知道；稀缺的是你的 attention 花在哪，以及你判断什么值得花。**培训班卖的是路径，而这条路，恰恰就是鲑鱼通道的付费版。**

以前你和别人的差距，是刷题量的差距，多熬几晚就能缩小。现在差距是主干和品味的差距，是你在审 diff 时能不能一眼看出那个 hooks 权限配错了——这种东西没有夜可以熬，只能沿着结构一层层搭上去。

所以我不觉得这轮变化是毁灭。它只是终于把「学习」这个词还给了它本来的意思：不是把时间兑换成题量，是把自己的判断力一层层建起来。

**鲑鱼还是会有，通道也还会有人排队去游。但你可以决定做一只鹈鹕——尤其是在河已经改道的时候。**
