<p>——————————-—本文旨在讨论和交流计算机知识，欢迎指正！！！—————————</p> <br><h3>题目描述</h3> <br><p>n 个人围成一圈，从第一个人开始报数,数到 m 的人出列，再由下一个人重新从 1 开始报数，数到 m 的人再出圈，依次类推，直到所有的人都出圈，请输出依次出圈人的编号。</p> <br><h3>输入格式</h3> <br><p>输入两个整数 n,m。</p> <br><h3>输出格式</h3> <br><p>输出一行 n 个整数，按顺序输出每个出圈人的编号。</p> <br><p>既然这一题要求我们输出出圈人的编号，我们用链表模拟的时候不用模拟值的数组，只用模拟首尾相连的过程即可； </p> <br><pre><code class="language-cpp">#include<bits/stdc++.h><br>using namespace std;<br>const int N=1e5+9;<br>int ne[N];<br>int n,m;//初始化<br></code></pre> <br><p>首先，我们模拟首尾相连的环状结构</p> <br><pre><code class="language-cpp"> cin>>n>>m;<br>    for(int i=1;i<=n;i++)<br>        {<br>            ne[i]=i+1;<br>        }//如衔尾蛇一般环环相扣，前一个的下一个是后一个的编号；<br>    ne[n]=1;//将第n个的下一个给第1个编号，完成闭环；</code></pre> <br><p>那么，如何进行删除呢？</p> <br><p>经过笔者冥思苦想 ，发现，我们只要遍历后删除并输出该位置前驱的下一个就行；</p> <br><p>例如：要删除2，我们找到2的前驱pre=1，ne[pre]=ne[ne[pre]]即可。</p> <br><p>即1的下一个等于1的下一个的下一个（相当于跳过了2）；</p> <br><pre><code class="language-cpp">int pre=n;//初始化1的前驱n<br>    for(int cnt=0;cnt<n;cnt++)//一共删除了n个数字<br>        {<br>            for(int j=0;j<m-1;j++)//走m-1步，找到第m步的前驱，即为待删点；<br>                {<br>                    pre=ne[pre];<br>                }<br>            cout<<ne[pre]<<" ";//输出删除编号；<br>            ne[pre]=ne[ne[pre]];//删除操作<br>        }</code></pre> <br><p>下面附上完整代码，希望可以有所帮助：</p> <br><pre><code class="language-cpp">#include<bits/stdc++.h><br>using namespace std;<br>const int N=1e5+9;<br>int ne[N];<br>int n,m;<br>int main()<br>{<br>    cin>>n>>m;<br>    for(int i=1;i<=n;i++)<br>        {<br>            ne[i]=i+1;<br>        }<br>    ne[n]=1;<br>    int pre=n;<br>    for(int cnt=0;cnt<n;cnt++)<br>        {<br>            for(int j=0;j<m-1;j++)<br>                {<br>                    pre=ne[pre];<br>                }<br>            cout<<ne[pre]<<" ";<br>            ne[pre]=ne[ne[pre]];<br>        }<br>    return 0;<br>}</code></pre> <br><p> </p> <br><p></p> <br><p> </p>
