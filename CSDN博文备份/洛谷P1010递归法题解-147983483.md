i >= 0; i--)<br>    {<br>        if (pow(2, i) <= n)<br>        {<br>            if (i == 0) {<br>                cout << "2(0)";//这里是对于2的0次方的断点<br>            }<br>            else if (i == 1)<br>            {<br>                cout << "2";//这里是对2的1次方的断点<br>            }<br>            else {<br>                cout << "2(";<br>                solve(i);//这个时候就是递归向下了，因为这个时候我们就要进行套括号的类似操作了<br>                cout << ")";<br>            }<br>            n -= pow(2, i);//拆解是线性相加来组成的，所以这里要-<br>            if (n != 0)cout << "+";<br>        }<br>    }<br>}</code></pre> <br><p>看到这里，也许你会有疑问：“为什么循环的次数是14次”，让我们看看这个题目的数据范围：“1≤n≤2×104” </p> <br><p> 那么，我们可以看看它最大到2的几次方，2的十四次方是16384,2的十五次方是32768，所以这里我们选取循环次数是14.并且，我们要从大到小开始循环，因为这个答案的形式是2的n次方从大到小开始的，所以我们要倒序遍历。</p> <br><p>遍历到最后就拆成0和1了。</p> <br><p>下面，我们来看看完成代码：</p> <br><pre><code class="language-cpp">#include<iostream><br>#include<algorithm><br>using namespace std;<br>int n;<br>void solve(int n)<br>{<br>    for (int i = 14;
